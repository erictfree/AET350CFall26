# Changelog

## 0.1.0 — 2026-09-15

Initial classroom prototype.

- Six composable shapes: circle, rectangle, line, star, orbit, and wave.
- Number-or-function arguments, with a general value evaluator inside the library.
- Shared bass, mid, and treble controls with configurable sensitivity.
- `init(song)` receives an already-loaded sound; the sketch owns loading and looping.
- Optional playback controls through `toggle()` and `isPlaying()`.
- Composition and one-circle examples for p5.js 2.3.3 and p5.sound 0.4.1.
- Student guide, parameter-by-parameter API reference, recipes, and source JSDoc.
- Dependency-free library and documentation checks for instructors.
