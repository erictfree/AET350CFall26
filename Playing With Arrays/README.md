# Playing With Arrays

A fullscreen p5.js sketch for experimenting with first-class and higher-order
JavaScript array functions.

Open `index.html` with VS Code Live Server. The display code and sample `numbers`
and `fruits` arrays live in `sketch.js`. Copy an example from `array-examples.js`
into `setup()` in `sketch.js`, then reload the page.

The sketch demonstrates `forEach`, `map`, `filter`, `reduce`, `find`, `some`,
`every`, `sort`, and method chaining. Each callback is an arrow function that is
passed to an array method.
