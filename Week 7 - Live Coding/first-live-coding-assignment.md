# First live coding assignment: Using Thunk Machine

We’ll use the live coding tool **Thunk Machine** for this assignment. To get started, go to [thunkmachine.com](https://thunkmachine.com) and launch it.

Create one scene that explores a visual relationship: overlap, contrast, balance, rhythm, or repetition.

Requirements:

- Create a background as its own layer.
- Write at least two patches of your own, each an object with a `draw` method.
- Make at least one visual property respond to audio and/or time.
- Include at least one Library patch and animate it by connecting a parameter to audio or time. You may change this patch any way you like.

If you like, you can also add shaders—we’ll see how in class.

Play some of your favorite music. **The challenge is to see whether you can make a simple scene like this interesting to perform, at least for a few bars of your music.** Experiment with the visuals and their response to the music. Try changing values live, then evaluating your edits. Use comments to temporarily remove and restore parts of the scene with **Cmd/Ctrl+/**, followed by **Cmd/Ctrl+Enter**.

**Practice and be ready to demonstrate your code live.**

**Record at least 30 seconds of yourself performing the scene.** You’re welcome to narrate what you’re doing, but narration is optional.

**To turn in:**

1. Add an **artist’s statement** as comments in your code above the scene array, describing your visual idea and how it connects to your chosen music. Don’t forget this—several people lost points on Assignment 4 simply because they didn’t submit one.
2. Go to the **Performance** tab, scroll to the bottom, and choose **Export performance**. Rename the exported file `lastname_firstname.json`.
3. Submit the exported performance and your video.

Thunk Machine is new software, so export your performance often to keep a backup of your work. Please report any bugs you encounter so we can get them fixed quickly.
